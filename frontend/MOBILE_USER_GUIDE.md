# SecurityOps 2.0 - Phase 11: Benutzerhandbuch Mobile Mitarbeiter-App

## 1. Schnellstart auf dem Dienstgerät
1. Öffnen Sie die Anwendung im Browser oder installieren Sie sie über das Browsermenü als App (PWA).
2. Oben rechts zeigt die Statusanzeige den aktuellen Netzwerkstatus (`Online` oder `Offline-Modus`).
3. Wechseln Sie bei Bedarf über die Schaltfläche **Mitarbeiter-App** in die Smartphone-Ansicht.

## 2. Kontrollgänge durchführen
- Tippen Sie in der unteren Navigationsleiste auf das zentrale **Scan**-Symbol.
- Richten Sie die Kamera auf den QR-Code des Kontrollpunkts oder halten Sie das Gerät an den NFC-Wandtransponder.
- Nach erfolgreichem Scan leuchtet die Bestätigung grün auf und der Scan wird mit Zeitstempel im Wachbuch archiviert.
