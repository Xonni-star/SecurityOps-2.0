# SecurityOps 2.0 - Phase 13: Mobile Abnahme & Hardware-Sensoren

## 1. Gerätefunktionen
- **Kamera & QR-Code**: Scanner über HTML5 MediaDevices mit visueller Zielerfassung aktiv.
- **NFC-Wandtransponder**: Unterstützung für Web NFC auf Android Dienstgeräten.
- **Touch-Targets**: Alle Schaltflächen der unteren Navigationsleiste entsprechen WCAG 2.2 AA (>= 44x44px).
- **Schichtübergabe & Diensttausch**: Vollständig mobil auf dem Smartphone durchführbar.
